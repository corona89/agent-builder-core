## Lessons Learned
- **Database Schema Consistency**: Always ensure Pydantic schemas (`schemas.py`) strictly match SQLAlchemy models (`models.py`) to avoid `ResponseValidationError` in FastAPI, especially when returning ORM objects.
- **Dynamic Endpoint Management**: Cloudflare quick tunnels change URLs on every restart. Using `sed` or environment variables to batch-update frontend source code is essential for rapid recovery.
- **PDF Parsing**: `pypdf` is a lightweight and effective solution for text extraction, but output should always be validated for empty content after extraction.
